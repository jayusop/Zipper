主要功能

常用操作一键完成，详细设置按需使用。

🗜️

创建、解压与编辑

创建和解压 ZIP、7Z、TAR、GZ。拖到窗口即可——压缩文件会被打开，其他文件会被压缩。无需解压即可编辑 ZIP。

📂

支持 30 多种格式

RAR、EGG、ALZ、ISO、CAB、LZH 以及许多旧格式，收到的压缩文件大多可以直接打开。

🔤

文件名不乱码

文件名以合成形式（NFC）保存，并自动识别 GBK、CP949、Shift-JIS 等代码页，Windows 压缩文件也能正确显示。

🔒

AES-256 加密

可为 ZIP 和 7Z 设置 AES-256 密码，7Z 还能隐藏文件名。也可解压加密的 EGG（AES/LEA）和 ALZ。

✨

智能解压

如果内容都在一个文件夹内则就地解压，否则先创建以压缩文件命名的文件夹，避免文件散落。

✂️

分卷压缩

可按邮件附件（25MB）、CD、DVD、FAT32（4GB）等大小分卷，分卷文件也能直接打开。

🧪

完整性测试与校验和

检测压缩文件是否损坏，并查看任意文件的 CRC32、MD5、SHA-1、SHA-256。

🧹

干净的压缩包

自动排除 .DS_Store、__MACOSX 和资源分支，压缩包在 Windows 上也干净整洁。

🌐

4 种语言 · 深色模式

支持韩语、英语、中文和日语，默认跟随系统语言。可选浅色/深色主题。

开始界面 — 打开压缩文件、新建压缩文件、拖放文件、快速 ZIP/7Z 压缩集中在一处

安装方法

只需将应用移到“应用程序”文件夹。

macOS 12 或更高版本通用版：Apple Silicon · Intel免费
  1. 下载从 GitHub Releases 页面下载最新的 Zipper.app.zip 并解压。
  2. 移到“应用程序”将 Zipper.app 拖到“应用程序”文件夹。
  3. 首次打开这是未经 Apple 公证的个人发布应用，首次打开时会出现安全提示。请不要点按 移到废纸篓，点按 完成（macOS 14 及更早版本为 取消）关闭，然后在 系统设置 → 隐私与安全性 底部点按 仍要打开。

如果使用终端，也可以运行这一行命令：

xattr -dr com.apple.quarantine /Applications/Zipper.app

常见问题

真的免费吗？

是的。个人和企业均可免费使用。

能解压 ALZ 和 EGG 吗？

可以，包括分卷 ALZ（.a00、.a01…）、加密文件，以及采用 AES/LEA 加密、固实压缩和分卷的 EGG。不支持创建 ALZ 或 EGG。

在 Windows 上解压时文件名会乱码吗？

不会。Zipper 按 Windows 期望的方式（NFC 并带 UTF-8 标志）保存文件名，在文件资源管理器中可正确显示。

能创建 RAR 吗？

RAR 仅支持打开和解压。创建时请使用 ZIP 或 7Z。

会联网或上传我的文件吗？

不会。所有操作都在你的 Mac 上完成。

如何切换语言？

默认跟随系统语言。可在 偏好设置 → 通用 → 语言 中更改，立即生效。

会公开源代码吗？

不会。Zipper 是只发布可执行应用的免费软件，不公开源代码。
