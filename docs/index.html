주요 기능

자주 쓰는 일은 한 번의 클릭으로, 세세한 설정은 필요할 때만.

🗜️

만들고 풀고 편집하기

ZIP, 7Z, TAR, GZ 압축 파일을 만들고 풉니다. ZIP은 풀지 않고도 파일 추가·삭제·이름 바꾸기가 가능합니다.

📂

30여 가지 형식 열기

RAR, EGG, ALZ, ISO, CAB, LZH 등 오래된 형식과 국내 형식까지, 받은 압축 파일을 대부분 바로 엽니다.

🇰🇷

한글 파일명 깨짐 방지

Mac의 분리된 자모(NFD)를 합쳐서(NFC) 저장하고, CP949 등 코드페이지를 자동 감지해 Windows 압축 파일도 올바르게 보여줍니다.

🔒

AES-256 암호화

ZIP과 7Z에 AES-256 암호를 걸 수 있고, 7Z는 파일 이름까지 숨길 수 있습니다. 암호화된 EGG(AES/LEA)·ALZ도 풉니다.

✨

스마트 풀기

내용이 한 폴더에 들어 있으면 그 자리에, 아니면 압축 파일 이름의 새 폴더에 풀어 파일이 흩어지지 않습니다.

✂️

분할 압축

메일 첨부(25MB), CD, DVD, FAT32(4GB) 등 원하는 크기로 나눠 압축하고, 분할된 파일도 그대로 엽니다.

🧪

무결성 테스트 · 체크섬

압축 파일이 손상되지 않았는지 테스트하고, 어떤 파일이든 CRC32·MD5·SHA-1·SHA-256 값을 확인합니다.

🧹

깔끔한 압축

.DS_Store, __MACOSX, 리소스 포크 같은 Mac 전용 파일을 빼고 압축해 Windows에서도 깔끔하게 보입니다.

🌐

4개 언어 · 다크 모드

한국어, 영어, 중국어, 일본어를 지원하며 시스템 언어를 따릅니다. 라이트/다크 테마를 고를 수 있습니다.

ZIP 파일은 압축을 풀지 않고 바로 편집할 수 있습니다. 분할 압축(.001, .z01, .a00, .vol1.egg, RAR 볼륨)과 EXE 자동 풀림 파일 안의 ZIP/7Z/RAR/ALZ/EGG도 열 수 있습니다.

설치 방법

다운로드한 앱을 응용 프로그램 폴더로 옮기기만 하면 됩니다.

macOS 12 이상Apple Silicon · Intel 유니버설무료
  1. 다운로드GitHub 릴리스 페이지에서 최신 Zipper.zip을 내려받아 압축을 풉니다.
  2. 응용 프로그램 폴더로 옮기기Zipper.app을 응용 프로그램 폴더로 드래그합니다.
  3. 처음 한 번 열기Apple 공증을 받지 않은 개인 배포 앱이라 처음 열 때 보안 경고가 뜹니다. 휴지통으로 이동은 누르지 말고 완료(macOS 14 이하는 취소)로 닫은 뒤, 시스템 설정 → 개인정보 보호 및 보안 아래쪽의 그래도 열기를 클릭하세요.

터미널을 쓴다면 다음 명령 한 줄로도 됩니다.

xattr -dr com.apple.quarantine /Applications/Zipper.app

자주 묻는 질문

정말 무료인가요?

네. 개인과 회사 모두 무료로 사용할 수 있습니다.

알집(ALZ), EGG 파일도 풀 수 있나요?

네. 분할된 ALZ(.a00, .a01…), 암호가 걸린 파일, EGG의 AES/LEA 암호화·솔리드·분할 압축도 풉니다. ALZ와 EGG는 만들기는 지원하지 않습니다.

Windows에서 압축을 풀면 한글 이름이 깨지지 않나요?

Zipper는 파일 이름을 Windows가 읽는 방식(NFC, UTF-8 표시)으로 저장하므로 Windows 탐색기에서도 한글 이름이 정상으로 보입니다.

RAR 파일을 만들 수 있나요?

RAR는 열고 풀기만 지원합니다. 만들 때는 ZIP이나 7Z를 사용하세요.

인터넷에 연결하거나 파일을 어딘가로 보내나요?

아니요. 모든 작업은 Mac 안에서만 이루어집니다.

언어는 어떻게 바꾸나요?

기본은 시스템 언어를 따릅니다. 환경설정 → 일반 → 언어에서 바꾸면 바로 적용됩니다.

소스 코드도 공개하나요?

아니요. Zipper는 실행 파일(앱)만 배포하는 프리웨어입니다. 소스 코드는 공개하지 않습니다.
