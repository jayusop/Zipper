Features

Everyday tasks in one click; detailed settings only when you need them.

🗜️

Create, extract, edit

Create and extract ZIP, 7Z, TAR and GZ. Drop files on the window — archives open, other files are compressed. Edit a ZIP without unpacking it.

📂

Opens 30+ formats

RAR, EGG, ALZ, ISO, CAB, LZH and many legacy formats — most archives you receive open right away.

🔤

No garbled file names

Names are stored in composed Unicode (NFC) and code pages such as CP949 or Shift-JIS are detected automatically, so Windows archives read correctly.

🔒

AES-256 encryption

Protect ZIP and 7Z archives with AES-256; 7Z can hide file names too. Encrypted EGG (AES/LEA) and ALZ archives extract as well.

✨

Smart extract

If everything sits in one folder it is extracted in place; otherwise a folder named after the archive is created, so files never spill out.

✂️

Split archives

Split into parts for e-mail (25 MB), CD, DVD or FAT32 (4 GB), and open multi-part archives directly.

🧪

Test & checksums

Verify an archive is intact, and see CRC32, MD5, SHA-1 and SHA-256 of any file.

🧹

Clean archives

Leaves out .DS_Store, __MACOSX and resource forks, so your archives look tidy on Windows.

🌐

4 languages · Dark mode

Korean, English, Chinese and Japanese, following your system language. Light and dark themes.

Installation

Just move the app into your Applications folder.

macOS 12 or laterUniversal: Apple Silicon · IntelFree
  1. DownloadGet the latest Zipper.app.zip from the GitHub Releases page and unzip it.
  2. Move to ApplicationsDrag Zipper.app into the Applications folder.
  3. Open it the first timeZipper is an independently distributed app that is not notarized by Apple, so macOS shows a warning the first time. Don't click Move to Trash — close it with Done (Cancel on macOS 14 and earlier), then click Open Anyway at the bottom of System Settings → Privacy & Security.

If you prefer Terminal, this one line does the same:

xattr -dr com.apple.quarantine /Applications/Zipper.app

FAQ

Is it really free?

Yes. Free for personal and business use.

Can it extract ALZ and EGG archives?

Yes — including split ALZ (.a00, .a01…), password-protected files, and EGG with AES/LEA encryption, solid mode and volumes. Creating ALZ or EGG is not supported.

Will file names break when extracted on Windows?

No. Zipper stores names the way Windows expects (NFC with the UTF-8 flag), so they display correctly in File Explorer.

Can it create RAR archives?

RAR is open and extract only. Use ZIP or 7Z to create archives.

Does it connect to the internet or upload my files?

No. Everything happens on your Mac.

How do I change the language?

It follows your system language by default. Change it in Preferences → General → Language; it applies immediately.

Is the source code available?

No. Zipper is freeware distributed as a compiled app only; the source code is not published.
